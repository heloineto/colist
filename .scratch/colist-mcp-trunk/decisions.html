Mapa completo · 15 nov 2026

9 decisões tomadas. Três mudanças prontas para implementar.

Pesquisei e decidi tudo sozinho, como você pediu. Cada decisão abaixo está marcada como um item de lista. Desmarque a que quiser mudar, escreva o que prefere, e copie tudo no botão de baixo para colar no Claude.

Branches

Só main. PR de branch de feature, merge = deploy.

Dependabot

semiannually: 1º de janeiro e 1º de julho.

MCP

8 tools em /api/mcp, OAuth pelo próprio better-auth.

Uma interpretação minha: entendi "o Claude deve conseguir dar capacidades" como "expor as funções do Colist como ferramentas (tools) para o Claude". E "adicionar itens de volta no carrinho" como desmarcar um item comprado para ele voltar à lista. Se era outra coisa, desmarque a decisão de tools.

Mudança 1

Aposentar a dev

Hoje dev e main estão idênticas, o deploy já só roda em push na main, e as roles OIDC da AWS já não conhecem dev. Então a troca é só limpeza.

Mudança 2

Dependabot de 6 em 6 meses

O GitHub tem intervalo nativo semiannually. O risco de esperar 6 meses é segurança, então os alertas de vulnerabilidade (hoje desligados) entram como rede de proteção.

Mudança 3

Servidor MCP do Colist

Você adiciona https://colist.heloineto.com/api/mcp como conector personalizado no claude.ai. Faz login no Colist uma vez, autoriza, e o Claude passa a mexer nas suas listas como você. Funciona no web, no app de celular e no Claude Code. Conectores estão em todos os planos (no Free, só um).

As 8 tools

Só tools: sem resources, prompts ou MCP Apps. Toda tool tem título e anotação, então o Claude roda leituras sem perguntar e sempre pede confirmação antes de apagar.

Tool O que faz Tipo

Ficaram de fora de propósito: apagar lista, sair da lista, adicionar/remover membros, renomear/apagar categoria, histórico, perfil. Cada um vira uma tool nova sobre um use-case que já existe.

Entrega

Três PRs, todos direto para main

  1. chore/trunk-based

    Branches + Dependabot num PR só. Depois: fechar os 11 PRs do Dependabot na dev, apagar dev, ligar alertas, e clicar "Check for updates" para os upgrades pendentes reabrirem contra a main.

  2. feat/mcp-oauth

    better-auth 1.7.25 + plugins, migration das tabelas OAuth, rota no Caddy, telas de consentimento e "Apps conectados".

  3. feat/mcp-server

    Controller MCP, extração da checagem de membro, as 8 tools, testes. Validação final: conectar no claude.ai, celular e Claude Code, e revogar.
