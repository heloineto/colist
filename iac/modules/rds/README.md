# rds

Single-AZ Postgres on RDS: `db.t4g.micro`, 20 GB gp3 encrypted, 7-day automated
backups, deletion protection, final snapshot on destroy.

The instance is **private**: inbound 5432 from the API security group only.
Local admin and the cutover load go through an SSM port-forward on the EC2
instance (`scripts/db-tunnel.sh`). A custom parameter group sets
`rds.force_ssl=1`, so every client must use SSL (`sslmode=require`).

The master password is **RDS-managed**: generated by RDS and stored in Secrets
Manager (`master_user_secret_arn`), never in Terraform state or git. Read it
with `aws secretsmanager get-secret-value --secret-id <arn>`.

`engine_version` is a major only (`17`), so minor upgrades are automatic. Keep it
at or above the source major when restoring a `pg_dump`.
